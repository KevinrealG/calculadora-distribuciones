Matrices Especiales

  • Identidad: filas/columnas con 1 en la diagonal.
  • Diagonal: solo entradas de la diagonal son distintas de cero.
  • Triangular: superior o inferior.
  • Simétrica: A = Aᵀ.

Propiedades

  • Determinante = 0: matriz singular.
  • Rango máximo: menor entre filas y columnas.
  • Traza: suma de elementos diagonales.
  • Inversa solo si det ≠ 0.

Aleatoria

Se puede generar matrices aleatorias con valores entre 0 y 1, o con una distribución específica para pruebas.

Guía rápida

  1. Elige la operación y crea la matriz con el tamaño deseado.
  2. Completa los valores numéricos.
  3. Usa “Resolver” para ver la solución.
  4. Para sistemas 2x2 y 3x3, ingresa los coeficientes.
